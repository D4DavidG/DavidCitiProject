# OpenAPI file: build plan

Spec: `docs/superpowers/specs/2026-10-14-openapi-design.md`. Each task is TDD: write the
test, run it and watch it fail for the stated reason, write the code, run it green, commit.
Stage files by name (never `git add -A`). Every commit message ends with a blank line and
`Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`. Per the 19:50 ruling, run only
the tests for this change; the final verify updates test counts.

```sh
cd /home/uc7dabfc1/DavidCitiProject
.venv/bin/pytest -q tests/backend/test_openapi.py          # this change
.venv/bin/pytest -q tests/backend/test_api.py              # handlers still behave (docstrings only)
.venv/bin/python tools/openapi.py                          # regenerate docs/openapi.json
```

No migration, no route change, no website change, so no Lambda cold start and no
Playwright run. The test needs no database: it never asks for the `conn` fixture.

How the test loads the tool (it lives in `tools/`, not on pytest's `pythonpath`):

```python
spec = importlib.util.spec_from_file_location("openapi_tool", ROOT / "tools" / "openapi.py")
openapi_tool = importlib.util.module_from_spec(spec); spec.loader.exec_module(openapi_tool)
```

## Task 2. The builder: paths, roles, auth, status codes

Tests (add to `test_openapi.py`; they call `openapi_tool.build()` directly):
- `test_every_route_is_documented_once`: for each route,
  `doc["paths"][route.path][route.method.lower()]` exists; total operations across all
  paths `== len(routes.ROUTES)`; `operationId`s unique and equal to handler names.
- `test_every_handler_has_a_one_line_docstring` (extend): each operation's `summary ==
  inspect.getdoc(handler).splitlines()[0]`.
- `test_roles_and_auth_follow_the_route_table`: top-level `security ==
  [{"bearerAuth": []}]`; `components.securitySchemes.bearerAuth == {"type": "http",
  "scheme": "bearer", "bearerFormat": "JWT"}`; public routes (`route.public`) have
  `security == []`, others have no `security` key; `op.get("x-roles")` equals
  `sorted(route.roles)` or is absent when `route.roles is None`.
- `test_status_codes_follow_the_route_table`: `POST /users` has `"201"`; `POST
  /auth/logout` has `"204"` with no `content`; `GET /projects` `"200"` refers to
  `#/components/schemas/Page` and has `page` and `pageSize` query parameters;
  `GET /users/{id}` has an `id` path parameter, `required: true`, `integer`;
  `POST /milestones/{id}/dependencies/{other_id}/archive` has both `id` and `other_id`;
  every non-public operation lists `"401"`, `"403"`, `"404"` referring to
  `#/components/responses/Error`; non-GET operations also list `"409"`.
- `test_every_ref_resolves`: walk the document, every `$ref` string `#/components/a/b`
  resolves; `doc["openapi"] == "3.0.3"`.

Fails first: `FileNotFoundError` / no such file `tools/openapi.py`.

Code: `tools/openapi.py` (module docstring: what it is, how to run it, that a test keeps
`docs/openapi.json` in step).
- `ROOT = Path(__file__).resolve().parents[1]`; `sys.path.insert(0, str(ROOT / "backend" / "tracker"))`;
  `from api import routes`; `OUT = ROOT / "docs" / "openapi.json"`.
- `SERVERS`: local `http://localhost:3001/api/tracker`, AWS
  `https://d1gov8jpsxhwer.cloudfront.net/api/tracker`, each with a description.
- `COMPONENTS`: `schemas.Error` (object; `error` string required; optional `field`,
  `code` strings), `schemas.Page` (object; `items` array of objects, `page`, `pageSize`,
  `total`, `totalPages` integers; all required), `responses.Error` (description "The
  standard error", JSON `$ref` Error), `securitySchemes.bearerAuth`.
- `_is_list(handler) -> bool`: `"_page(" in inspect.getsource(handler) or "_whole(" in ...`.
  `_is_paged(handler)`: `"_page(" in` source (gets `page`/`pageSize` query params).
- `_operation(route) -> dict`: `operationId` = handler name, `summary` = first docstring
  line, `tags` = `[route.path.split("/")[1]]`, `description` = "Roles: ADMIN, MANAGER" or
  "Any signed-in user" or "Public: no token", plus " Allowed before the first password
  change." when `allowed_before_password_change`; `x-roles` when roles set; `security: []`
  when public; `parameters` (path params from `re.findall(r"\{(\w+)\}", path)`, then query
  params); `responses` (success code `str(route.status)`; 204 has description only; list
  handlers `$ref` Page, others `{"type": "object"}`; then `"400"`; non-public adds
  `"401"`, `"403"`, `"404"`; non-GET adds `"409"`).
- `build() -> dict`: `{"openapi": "3.0.3", "info": {"title": "ACME Project Tracker API",
  "version": "1.0.0", "description": ...}, "servers": SERVERS, "security":
  [{"bearerAuth": []}], "tags": [...], "paths": {...}, "components": COMPONENTS}`; paths
  in route-table order.
- `write() -> None`: `OUT.write_text(json.dumps(build(), indent=2) + "\n")`, print
  "Wrote docs/openapi.json: N operations". `if __name__ == "__main__": write()`.

**Commit:** "OpenAPI: tools/openapi.py builds the file from the route table".

## Task 3. Request bodies and query filters

Tests:
- `test_bodies_are_listed_for_exactly_the_handlers_that_read_one`: `{r.handler.__name__
  for r in ROUTES if "ctx.body" in inspect.getsource(r.handler)} ==
  set(openapi_tool.BODIES)` (23 today), and each such operation has
  `requestBody.content["application/json"].schema.properties` with those keys.
- `test_body_fields_match_the_service_allow_lists`: a small table in the test, handler ->
  allow-list, compared after camelCasing (`api.http.to_camel`):
  `create_user`/`admin_update_user` -> `users._ADMIN_FIELDS`; `update_me` ->
  `users._PROFILE_FIELDS`; `set_capacity` -> `users._CAPACITY_FIELDS`;
  `create_project`/`update_project` -> `projects._ADMIN_FIELDS`; `create_booking` ->
  `assignments._FIELDS`; `update_booking` -> `assignments._FIELDS - {"user_id"}`;
  `create_milestone`/`update_milestone` -> `milestones._FIELDS`; `create_task`/`update_task`
  -> `tasks._FIELDS`; `log_time`/`edit_time` -> `time_entries._FIELDS`; `create_request` ->
  `{"kind"} | union of requests._FIELDS.values()`.
- `test_types_follow_the_validators`: spot checks: `create_booking.hoursPerWeek` is
  `integer`; `log_time.workDate` is `string` with `format: date`; `set_capacity.overtimeAllowed`
  is `boolean`; `create_project.budgetCents` is `integer`.
- `test_filters_are_documented`: `GET /projects` has `search`, `status`,
  `includeArchived`; `GET /notifications` has `unread`; `GET /dashboard/allocation` has
  `overOnly`, `weekFrom`, `weeks`.

Fails first: `AttributeError: module 'openapi_tool' has no attribute 'BODIES'`.

Code: in `tools/openapi.py`,
- `INT, BOOL, TEXT, DATE = {"type": "integer"}, {"type": "boolean"}, {"type": "string"}, {"type": "string", "format": "date"}`.
- `BODIES`: handler name -> `{camelField: type}`, 23 entries, types read from the
  service's `values.*` call for each field (spec section 3). Login: `username`,
  `password`; refresh/logout: `refreshToken`; change password: `currentPassword`,
  `newPassword`; dependency: `dependsOnMilestoneId`; move: `status`; approve request:
  `startDate`, `predictedEndDate`, `decisionNote`; reject: `decisionNote`.
- `FILTERS`: handler name -> `{queryName: type}`, read from each service's
  `values.*(filters, ...)` calls and `api/http.py`'s `INT_QUERY_KEYS`/`BOOL_QUERY_KEYS`
  (grep `values\.\w*(filters` in `services/`).
- `_operation` adds `requestBody` (`required: True`, JSON schema `{"type": "object",
  "properties": BODIES[name]}`) and the filter query parameters.

**Commit:** "OpenAPI: request bodies and filters, checked against the services' allow-lists".
