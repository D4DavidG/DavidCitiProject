## Task 7. Website: the confirm dialog

File: `frontend/src/pages/mytasks/MyTasksPage.jsx`. State `overCapacity` = `{ message, send }`.
A helper inside the page:

```
async function sendTime(send, body) {   // send(body) -> Promise
  try { await send(body) } catch (failure) {
    if (failure.code !== 'OVER_CAPACITY') throw failure
    setOverCapacity({ message: failure.message, send: () => send({ ...body, confirmOverCapacity: true }) })
  }
}
```

Log and edit `onSubmit` call `sendTime`. Render `ConfirmDialog` (title "Over your weekly
capacity", message = server text, `confirmLabel="Log anyway"`, `onConfirm` = `overCapacity.send`,
`onClose` clears it). The success message and `entries.reload()` move into `send`. Update the
page docstring.

Tests in `MyTasksPage.test.jsx` (fetch mocked as the file already does):

- `it('sends nothing more when the person cancels')`: click "Cancel"; only one POST was sent.
- `it('shows other refusals in the form as before')`: a 409 without a code shows its message in the log form.

**Commit:** "Overtime: the log-time form asks Log anyway or Cancel".
