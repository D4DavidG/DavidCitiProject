## Task 1. The service: one person's trail

File: `backend/tracker/services/audit.py`.
- Extract `_date_filters(filters: dict, where: list, params: dict) -> None` from
  `list_audit` (appends the `date_from` / `date_to` fragments; `list_audit` calls it).
- `person_history(conn, actor, user_id, filters, page, page_size) -> dict`, docstring
  "One person's trail: changes they made and changes to their account, newest first."
  Access: `row = SELECT manager_id FROM users WHERE user_id = %s`; allowed when
  `actor.is_admin or actor.user_id == user_id or (actor.is_manager and row["manager_id"] == actor.user_id)`;
  otherwise (or `row is None`) `raise NotFound("User not found.")`.
  Filters: `action` via `values.text(..., required=False, max_length=64)`, upper-cased,
  exact match; then `_date_filters`. Query as in spec section 4 (scalar subquery for
  `actor_name`); `paginate(..., sql.SQL("audit_id DESC"), ...)`.
- Module docstring: one line on history and who reads it.

Tests in `tests/backend/test_audit.py` (setup in each: `users.update_self(alice, first_name="Alicia")`,
`users.set_capacity(boss, alice.user_id, {"weekly_capacity_hours": 30})`, and an unrelated
`users.update_self(loner, ...)`):
- `test_history_holds_changes_by_and_to_the_person`: as admin, `total == 3` (account
  created by admin, profile edit, capacity) ; summaries in `audit_id` descending order;
  no summary mentions Lone.
- `test_line_manager_admin_and_self_may_read_history`: boss, admin, alice each get `total == 3`.
- `test_others_get_404_like_a_missing_user`: loner (employee) and a new manager
  (`f.person(conn, admin, role="MANAGER")`) each raise `NotFound` with `str() == "User not found."`,
  and so does admin for `user_id=999999`.
- `test_history_filters_by_action_and_date`: `{"action": "update"}` -> 2 rows, all `UPDATE`;
  today = `conn.execute("SELECT current_date AS d").fetchone()["d"]`; `date_to` = yesterday -> 0;
  `date_from` = today -> 3.
- `test_history_is_paginated`: `page_size=1` -> `total == 3`, `total_pages == 3`, 1 item.

Fails first: `AttributeError: module 'services.audit' has no attribute 'person_history'`.
Also run the existing `test_admin_filters_the_audit_log` (the helper refactor).
