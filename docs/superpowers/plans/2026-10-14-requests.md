## Task 3. Sending a request of each kind

File: `backend/tracker/services/requests.py`. Add at the top:

```python
SENDERS = {"NEW_PROJECT": {"MANAGER"}, "ARCHIVE_PROJECT": {"MANAGER"},
           "TASK_LIMIT": {"EMPLOYEE"}, "OVERTIME": {"EMPLOYEE"}, "OTHER": {"MANAGER", "EMPLOYEE"}}
_FIELDS = {"NEW_PROJECT": {...existing five}, "ARCHIVE_PROJECT": {"project_id", "justification"},
           "TASK_LIMIT": {"task_limit", "justification"}, "OVERTIME": {"justification"},
           "OTHER": {"name", "justification"}}
```

`create_request(conn, actor, data)`: read `kind` with `values.choice` (400 if unknown);
Forbidden if `actor.role not in SENDERS[kind]`; `values.only_allowed(data, _FIELDS[kind] | {"kind"})`;
then one small branch per kind that fills `name` (spec decision 4):
`ARCHIVE_PROJECT` uses `access.visible_project` plus `manager_id == actor.user_id` (else
NotFound with the project message) and Conflict if archived; `TASK_LIMIT` reads
`values.integer(..., minimum=1, maximum=10)` and refuses (400, field `task_limit`) unless
above the stored `users.task_limit`; `OVERTIME` is Conflict if `overtime_allowed` is already on.
Audit summary: `NEW_PROJECT` keeps today's text; others "`{actor.name}` sent a request: `{name}`".

Tests in `tests/backend/test_requests.py` (extend `org`; helper `ask(conn, who, kind, **fields)`):

**Commit:** "Requests: managers and employees send their own kinds".

## Task 4. Who sees what: Mine and To decide

`requests.py`. One SQL fragment shared by list and get, over
`project_requests r JOIN users u ON u.user_id = r.requested_by`:

```python
_MAY_DECIDE = "(r.requested_by <> %(me)s AND (%(admin)s OR (u.role = 'EMPLOYEE' AND u.manager_id = %(me)s)))"
_MAY_SEE = f"(r.requested_by = %(me)s OR {_MAY_DECIDE})"
```

`list_requests` selects `r.*, u.first_name || ' ' || u.last_name AS requester_name`;

## Task 5. Deciding, with the effect and the asker told

`requests.py`. `_pending(conn, actor, request_id)`: Forbidden if `actor.is_employee`; the
row comes from `get_request(..., lock=True)` re-checked against `_MAY_DECIDE` (NotFound if
the actor only asked it); Conflict unless `PENDING`. `approve_request` validates fields by
kind (`NEW_PROJECT`: today's four; others: `{"decision_note"}`), then calls
`_apply(conn, actor, row, data) -> dict | None`:
`NEW_PROJECT` today's code moved here; `ARCHIVE_PROJECT` -> `projects.archive_project(conn, actor, row["project_id"])`;
`TASK_LIMIT` -> `users.set_capacity(conn, actor, row["requested_by"], {"task_limit": row["task_limit"]})`;
`OVERTIME` -> `users.set_capacity(..., {"overtime_allowed": True})`; `OTHER` -> None.
It returns `{"request": row, "project": project_or_None}`. Approve and reject call
`record_change(..., also_notify=row["requested_by"])` with the summary
"`{actor.name}` approved `{requester_name}`'s request: `{name}`" (rejected likewise).

Tests:

- `test_approving_an_archive_request_archives_the_project_and_its_work`: project and its tasks archived; audit has `APPROVE` on `project_requests` and `ARCHIVE` on `projects`.
- `test_approving_a_task_limit_request_sets_the_limit` (Bob decides) and `test_approving_overtime_turns_it_on` (admin decides).
- `test_approving_free_text_changes_only_the_request`: users and projects row counts and Alice's settings unchanged.
- `test_rejecting_changes_nothing_but_the_request` (task limit stays 2).
- `test_another_manager_cannot_decide_my_report_request`: Carol gets NotFound.
- `test_manager_cannot_decide_a_managers_request`: Bob approving Carol's `OTHER` gets NotFound (only admins decide managers' requests).
- `test_decision_notifies_the_asker`: Alice has a notification for the APPROVE audit row; Bob (the actor) has none.
- `test_archive_approval_is_409_if_already_archived_and_leaves_the_request_pending`.
- Existing approval, decide-once and `test_managers_cannot_decide_requests` (now NotFound for a manager on a manager's request; update the expected error) stay green.

**Commit:** "Requests: approving applies the change through the existing services; the asker is notified".
