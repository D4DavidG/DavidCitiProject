## Task 4. `services/sessions.py`: open, rotate, end, revoke_all

Signatures (docstring and type hints on each):

```python
REFRESH_LIFETIME = dt.timedelta(hours=8)
def open(conn, user_id: int, secret: str, now: dt.datetime) -> dict      # {"token", "refresh_token"}
def rotate(conn, raw: str, secret: str, now: dt.datetime) -> dict        # same shape, or AuthenticationError
def end(conn, raw: str | None, now: dt.datetime) -> None                 # revoke if live; never raises
def revoke_all(conn, user_id: int, now: dt.datetime) -> None
def _hash(raw: str) -> str                                               # hashlib.sha256(raw.encode()).hexdigest()
```

`open` is named `start` if `open` shadowing the builtin bothers lint/bandit.

- Tests first (`tests/backend/test_sessions.py`, new; no `api` import):
  - `test_only_the_hash_is_stored`: row `token_hash == sha256(raw)`; raw appears in no column.
  - `test_refresh_token_expires_eight_hours_after_login`: `expires_at == NOW + 8 h`.
  - `test_rotate_gives_a_new_pair_and_retires_the_old_one`: new raw differs; old row
    `revoked_at == now`, `replaced_by == new id`; new access token verifies to the user.
  - `test_rotation_keeps_the_original_expiry`: rotate at +7 h 59 min, new row `expires_at == NOW + 8 h`;
    rotate that one at +8 h -> `AuthenticationError`.
  - `test_reusing_a_rotated_token_revokes_everything`: rotate A -> B; rotate A again ->
    `AuthenticationError`; then B has `revoked_at` set and rotating B fails too. (Proves
    the revocation is kept although the call raised.)
  - `test_unknown_or_malformed_token_is_refused` (parametrize `None`, `""`, `"x"`): 401, nothing revoked.
  - `test_archived_user_cannot_refresh`.
  - `test_end_revokes_and_is_safe_twice`: `end` twice, and `end(conn, "nope", now)` returns None.
  - `test_revoke_all_only_touches_that_user`.
- Code: `rotate` selects the row by hash `FOR UPDATE` joined to `users`. Live and not
  expired and user not archived: insert the new row with the same `expires_at`, update
  the old (`revoked_at`, `replaced_by`). Already revoked: `revoke_all` inside
  `with atomic(conn):`, `logger.warning("refresh token reuse for user %s", user_id)`,
  then raise **outside** the block. Every refusal raises
  `AuthenticationError(tokens.INVALID_MESSAGE)`.
- Commit: "Sessions: refresh tokens with rotation and reuse detection".
